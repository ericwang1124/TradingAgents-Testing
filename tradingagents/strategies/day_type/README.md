# 10:00 判断开盘类型：顺势、反转，还是不做

```bash
python -m tradingagents.strategies.day_type          # SPY，结果写入 results/opening_reversal/DAY_TYPE.md
```

在 10:00 用盘前 9:00–9:30 和开盘前 30 分钟的行情判断当天的类型，然后选择：顺着 9:30–10:00 的方向做（**顺势**），反着做（**反转**），或者不做；持有到 12:00 或收盘。

用到的信息包括：
- 盘前走势和成交量
- 开盘 30 分钟的涨跌和开盘区间宽度（都以 ATR 为单位）
- **效率** = 净涨跌 ÷ 1 分钟走势的绝对值之和，越接近 1 越是单边，越接近 0 越是来回震荡
- 10:00 价格在开盘区间中的位置、与 VWAP 的距离、相对成交量
- 跳空幅度、开盘是否在前一日区间内、开盘区间是否突破前一日高点或低点
- VIX 和趋势

## 结果（2021–2026 全部为滚动样本外，不加杠杆，含成本）

| 方法（持有到 12:00） | SPY 夏普 | 2024-05 以后 |
|---|---:|---:|
| 每天都顺势 | 0.22 | 0.01 |
| 每天都反转 | −0.35 | −0.11 |
| Dalton 固定规则（单边 → 顺势，震荡 → 反转） | 0.21 | 0.58 |
| 学习出来的映射（分格 / 决策树 / 岭回归） | −0.31 / −0.15 / 0.33 | 不稳定 |
| **高效率日顺势**（效率 ≥ 过去数据的 2/3 分位数） | **0.86** | **0.75** |

- **反转在所有设置下都是负的**，逆着开盘方向做在这段时间里一直亏钱。
- **高效率日顺势**：478 笔，平均每笔 +4.4 个基点，胜率 57%，t = 2.08。门槛从 0 提高到 0.67 分位数，夏普从 0.22 平滑升到 0.86，再往上交易次数太少才回落。
  - 多头一侧：265 笔，平均 5.9 个基点，胜率 62%，t = 2.33。
  - 空头一侧：213 笔，平均 2.4 个基点，t = 0.69，不显著。
- **换标的检验（规则原样不改）**：
  - QQQ：0.69（到 12:00）、0.87（到收盘），复现了。但 QQQ 和 SPY 相关性高，这个证据偏弱。
  - IWM：−0.11，没有复现。小盘股反而是低效率日延续得最好。
  - 所以这个规律可能只在 SPY、QQQ 这类大盘指数上成立。
- **"每天都在 10:00 顺势、持有到收盘"在三只 ETF 上都是正的**：SPY 0.23、QQQ 0.52、IWM 0.60。三只等波动组合是 0.53，没有超过单独用 SPY 的高效率规则。

## 注意

- "效率"这个指标是在看过 SPY 全样本分组表之后才选中的，存在数据窥探的风险。门槛每年只用过去的数据计算，并在 QQQ 和 IWM 上做了检验，但真实预期应该打折扣，按夏普约 0.5–0.7 估计。
- 平均每笔优势约 0.31 美元/股（SPY 约 700 美元时）。0DTE 平值期权每张只能吃到约 15 美元，而 10:00 到 12:00 的时间价值损耗约 40–55 美元/张，所以**不适合用 0DTE 期权买方来做**，应该用股票、到期日更远的期权，或者价差组合。

仅作研究，不构成投资建议。
