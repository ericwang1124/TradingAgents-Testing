# 早盘低开反抽做空（SPY）— 第一阶段回测

把"开盘一小时、低开后冲高遇阻做空 SPY 0DTE put"写成固定规则，用 SPY 1 分钟 K 线回测，
先回答**信号本身在标的上有没有优势**。结果单位是 R（盈亏 ÷ 初始止损距离），**不是期权盈亏**。

与 LLM 多智能体框架完全独立，不需要任何 LLM API key。

## 规则

| 条件 | 规则化定义（参数见 `config.py`） |
|---|---|
| ① 低开 | 9:30 开盘价比昨收低 0.15%–2% |
| ② 价涨量缩 | 从当日低点起的反弹中，最后 3 根 K 线的**相对成交量**均值 ≤ 前 3 根的 80%。相对成交量 = 成交量 ÷ 过去 20 天同一分钟的成交量中位数，用来排除开盘后成交量自然衰减的干扰 |
| ③ 供给区遇阻 | 开盘前算好的价位 ± 0.05%：昨收、昨低、昨高、昨日成交量分布的 POC / VAH / VAL、盘前高点。反弹触及区域且收盘没站上去，然后一根阴线收在区域下方并跌破前一根低点 |
| 入场 | 信号 K 线的下一根开盘价，只在 9:35–10:30 之间入场，每天最多一笔 |
| 止损 | max(反弹高点, 区域上沿) + 0.03%；止损距离不在 0.05%–0.6% 的不做 |
| 止盈 | 1R 平一半并把止损移到保本，2R 平剩下一半；12:00 还没走完就全部平掉 |
| 成本 | 每次成交 0.002% 滑点（约 1 美分） |

同时跑 5 个版本，看每加一个条件到底有没有用：`gap_only`、`gap+exhaustion`、`gap+zone`、
`full`，以及对照组 `control: no gap-down`（非低开日用同一套量缩 + 供给区规则）。

## 第一阶段结果（2019-01-02 至 2026-11-12，1978 个交易日）

数据为 Alpaca SIP 1 分钟线（已复权），其中 587 天低开 ≥ 0.15%。单位是 SPY 本身的 R，不是期权盈亏。

| 版本 | 笔数 | 胜率 | 平均 R | 累计 R | 盈亏比（PF） | t 值 |
|---|---:|---:|---:|---:|---:|---:|
| 只看低开 | 572 | 49.7% | −0.03 | −16.2 | 0.95 | −0.63 |
| 低开 + 量缩 | 285 | 48.8% | −0.08 | −22.4 | 0.85 | −1.27 |
| 低开 + 供给区 | 286 | 44.8% | −0.12 | −34.2 | 0.78 | −1.95 |
| **三个条件全满足** | 92 | 47.8% | **−0.14** | −13.1 | 0.73 | −1.41 |
| 对照组：非低开日 | 123 | 39.8% | −0.22 | −26.8 | 0.63 | −2.41 |

- 五个版本全部是负期望，而且条件加得越多结果越差。用成交量近似出来的"量缩"和用固定价位定义的"供给区"都没有带来优势。
- 敏感性分析：最小低开幅度、量缩阈值、最小反弹幅度、区域宽度、入场截止时间、平仓时间、止盈方案，共 19 组参数里 17 组是负期望。唯一为正的是低开 ≥ 0.5% 那组，只有 31 笔，t = 0.15，和随机没有区别。
- 把止损缓冲放宽到 0.1% 或 0.2% 也没用，完整版本反而降到 −0.24 到 −0.28R（t ≈ −2.8），所以亏损不是止损太紧造成的。
- 最简单的基准：每个低开日 9:35 开空、12:00 平仓，平均每笔 +0.012%，t = 0.49，说明低开日的开盘一小时本身没有可利用的方向性。
- 结论：按这套规则写下来的版本在 SPY 上没有优势，还没算 0DTE 期权的价差和时间价值损耗。如果原作者确实能赚钱，优势只可能来自足迹图（逐笔订单流），或者来自没法写成规则的主观判断，这正是第二阶段要验证的。

## 参数优化（训练集选参数，测试集验证）

```bash
python -m tradingagents.strategies.opening_reversal.optimize --start 2019-01-01 --split 2023-01-01
```

一共 192 组参数组合：K 线周期 1 / 5 分钟、最小低开幅度 0.15% / 0.3% / 0.5%、大盘趋势过滤（不过滤 / 昨收低于 20 日均线）、条件组合（4 种）、入场确认（跌破前 1 根 / 前 3 根 K 线低点）、出场方式（1R 全平 / 1R 和 2R 各平一半）。
只用训练期 2019–2022（1008 个交易日）挑参数，再拿测试期 2023–2026（970 个交易日）检验。

| | 训练期 | 测试期 |
|---|---|---|
| 训练期最好的一组（1 分钟、低开 ≥ 0.3%、昨收低于 20 日均线、低开 + 量缩、1R 全平） | 39 笔，胜率 79%，平均 +0.57R，t = 4.3 | **42 笔，胜率 36%，平均 −0.31R，t = −2.1** |
| 原始规则 | 53 笔，平均 −0.16R | 39 笔，平均 −0.12R |

- 训练期和测试期表现的排名相关系数是 **−0.42**：训练期越好的参数，测试期反而越差。这说明"优化"只是在拟合 2019–2022 的噪音。
- "量缩"和"供给区"这两个条件的效果在两个时期正负颠倒，不稳定。
- 两个时期方向一致的只有三点：低开越大越好、只在跌势里做（昨收低于 20 日均线）、用 5 分钟 K 线。但即使三者都满足，平均也只有 +0.02 到 +0.09R，t < 0.5，不够覆盖 0DTE 期权的成本。
- 结论：用 K 线和成交量能写出来的规则，调参调不出稳定的优势。要再往下研究，必须换信息源，比如逐笔订单流。

## 已知局限

- "买盘衰竭"只用了成交量近似，真正的足迹图（主动买卖量、delta 背离、吸收）要逐笔成交加买卖盘数据，属于第二阶段。
- "有承接就止盈"用固定的 R 倍数代替了，同样要订单流数据才能做。
- 同一根 K 线里同时碰到止损和止盈时，按先止损计算（偏保守）。
- 期权盈亏、价差、选多少 delta 的合约是第三阶段，要用真实的 0DTE 历史报价。

仅作研究，不构成投资建议。
