# 强势股突破：在形态打分上加入财报、板块和大盘环境（2026-11-14）

> 代码：`python -m tradingagents.strategies.vcp.leaders --holdout`，完整结果在 `results/opening_reversal/LEADERS.md`。前两步见 `reports/JLaw_VCP_回测.md`。研究用途，不构成投资建议。

## 做了什么

起点是上一版的弹性规则：7 项形态打分，突破和回踩都等确认后再买。这一版不再以复现 J Law 为目标，而是加入我认为可能有用的信息。

**新增 5 个打分项**（每项 0–1 分，和原来 7 项等权相加）：

| 新增项 | 定义 | 数据来源 |
|---|---|---|
| 财报 | 最近一份季报（95 天内）EPS 和营收都超预期得 1 分，只有一项超预期且另一项没有不及预期得 0.5 分 | Alpaca 新闻里带时间戳的财报标题 |
| 指引 | 95 天内上调过业绩指引，或给出的指引高于预期 | 同上 |
| 分析师 | 60 天内上调目标价和评级的次数减去下调次数，3 次以上得 1 分 | 同上 |
| 板块 | 和这只股票走势最相关的 20 只股票，一年涨幅排名的平均值 | 用价格相关性每月重新找同伴，代替行业分类 |
| 趋势线 | 形态的高点逐步下降，而收盘已经站上连接最后两个高点的趋势线 | 价格 |

新闻只用突破当天收盘前已经发布的。退市股票也有新闻，改名的公司按新旧代码一起查。85% 左右的突破事件能找到并解析出最近一份季报。

**大盘环境**，三个候选：
- M0：不加。
- M1：按环境分调仓位。环境分看四项：SPY 在 50 日线上、全市场一半以上股票在 50 日线上、VIX 低于 3 个月 VIX、高收益债相对投资级债走强。得分低就减仓或不做；近期全市场的突破大多失败时再减半。
- M2：在 M1 基础上加入趋势反转。大盘跌过 8% 以上、重新站上 20 日线的那段时间，仓位加到 1.5 倍。

**检验流程**：规则先提交（`b568100`）。2017–2021 年比较三个候选，选出最好的并提交冻结（`954cb58`），2022–2026 年只跑一次。检验期在上一版用过一次，所以只对这次新增的内容算干净。

## 结果

一共 1,085 个突破事件，只做打分排在前四分之一的。

| | 开发期 2017–21 | | | 检验期 2022–26 | | |
|---|---:|---:|---:|---:|---:|---:|
| | 夏普 | 笔数 | 胜率 / 每笔 | 夏普 | 笔数 | 胜率 / 每笔 |
| **12 项打分，M0（冻结）** | 0.02 | 79 | 33% / +0.02R | **0.31** | 93 | 38% / +0.29R |
| 12 项打分，M1 | 0.02 | 76 | 33% / −0.01R | 0.27 | 84 | 36% / +0.29R |
| 12 项打分，M2（含反转加仓） | 0.00 | 77 | 34% / +0.04R | 0.23 | 87 | 37% / +0.30R |
| 只用原来 7 项形态打分 | 0.72 | 87 | 40% / +0.49R | 0.53 | 80 | 45% / +0.39R |
| SPY 买入持有 | 0.94 | | | 0.49 | | |

"每笔"是平均每笔赚到的风险倍数。

**加了新信息以后变差了。** 两段时间里，12 项打分都不如只看形态的 7 项打分；三种大盘处理方式之间没有差别。

## 逐项看：哪些因素在两段时间里一致

做法：把全部突破事件都在确认当天收盘买入，不按打分筛选，比较某一项高和低的两组平均每笔赚多少。t 值是两组差异的显著程度，绝对值超过 2 才算比较可靠。

| 因素 | 开发期：高 / 低 | t | 检验期：高 / 低 | t | 是否一致 |
|---|---|---:|---|---:|---|
| 收缩 3–4 次 | +0.49R / −0.06R | 1.9 | +0.48R / −0.15R | 1.9 | 一致 |
| 最后一次下跌缩量 | +0.34R / −0.15R | 2.0 | +0.29R / −0.21R | 2.0 | 一致 |
| 第一次回调 20%–35% | +0.88R / −0.11R | 2.6 | +0.32R / −0.08R | 1.4 | 一致 |
| 一年涨幅排名高 | +0.39R / −0.14R | 2.0 | +0.13R / −0.07R | 0.8 | 方向一致，变弱 |
| 上调指引 | +0.21R / +0.01R | 0.8 | +0.26R / −0.09R | 1.1 | 方向一致，都不显著 |
| 财报超预期 | −0.07R / +0.23R | −1.2 | +0.01R / −0.02R | 0.1 | 没有信息 |
| 分析师上调 | −0.08R / +0.24R | −1.3 | +0.02R / −0.05R | 0.3 | 没有信息 |
| 板块强 | +0.24R / −0.17R | 1.6 | −0.21R / +0.23R | −1.8 | 方向相反 |
| 趋势线突破 | −0.02R / +0.09R | −0.4 | +0.17R / −0.03R | 0.5 | 没有信息 |
| 平顶（水平阻力） | +0.03R / +0.16R | −0.5 | −0.01R / +0.01R | −0.1 | 没有信息 |
| 近期有过放量大涨 | +0.06R / +0.08R | −0.1 | +0.42R / −0.12R | 1.4 | 不一致 |
| 大盘环境分 ≥ 3 | +0.09R / −0.03R | 0.4 | +0.06R / −0.11R | 0.7 | 方向一致，很弱 |
| 大盘反转窗口 | −0.42R / +0.16R | −1.5 | +0.05R / −0.03R | 0.3 | 不一致 |
| 近期突破成功率高 | −0.04R / +0.58R | −1.8 | +0.13R / −0.35R | 2.3 | 方向相反 |
| 7 项形态总分（前四分之一对其余） | +0.61R / −0.11R | 2.2 | +0.51R / −0.17R | 2.0 | 一致 |

## 怎么读

1. **有信息的是价格和成交量的结构本身。** 收缩次数、缩量、第一次回调的深度，这三项在两段时间里方向和大小都差不多。"收缩次数"在检验期不算干净，原因见前一份报告。
2. **财报超预期和分析师上调没有帮助。** 一个可能的解释：选股条件已经要求一年涨幅排在前 20%、离高点不到 15%，这样的股票大多本来就财报好、被上调过，这些公开信息已经反映在价格里了。
3. **上调指引是新增信息里唯一方向一致的**，但两段时间都不显著。J Law 的 SMCI 那笔交易靠的正是上调指引。
4. **板块强度、近期突破成功率这两项方向相反**：一段时间里是正的，另一段时间里是负的。如果只看一段时间，很容易把它们当成有效规则。
5. **大盘环境和趋势反转没有稳定的作用。** 反转窗口里的突破在开发期更差，在检验期没有区别。和之前在 ETF 组合上的结论一样：按市场状态调仓位，样本外站不住。
6. **等权相加会稀释。** 12 项里有 5 项基本是噪音，把它们和有信息的项等权相加，选出来的前四分之一反而更差。

样本量是主要限制：每段时间只有 170 笔左右，只有差别达到每笔 0.5 倍风险左右才检测得出来。所以"没有帮助"的准确说法是"没有看到帮助"。

## 这条线的总体结论

| 版本 | 全期夏普 | 笔数 | 胜率 | 每笔 |
|---|---:|---:|---:|---:|
| 固定规则 | 0.17 | 341 | 30% | +0.16R |
| 7 项形态打分 + 确认后买入 | 0.63 | 167 | 43% | +0.44R（t = 2.6） |
| 再加财报、板块等 5 项 | 0.16 | 172 | 35% | +0.17R |

- 最好的仍然是 7 项形态打分。它在检验期的两次测试里每笔赚 +0.33R 到 +0.39R，t 在 1.7 左右，方向一致但不到显著。
- 它对组合夏普没有贡献：一年不到 20 笔，平均只占用 5% 左右的资金，加进核心组合后夏普不变（2019–26 年 1.019 → 1.008 到 1.024）。
- 合适的定位是选股清单，由人来做最后的判断。
