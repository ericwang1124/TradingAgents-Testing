# "散户版 TOPS"：知名交易员的方法 + 按历史表现加权（2026-11-17）

> 代码：`python -m tradingagents.strategies.vcp.retail_tops`，完整结果在 `results/opening_reversal/RETAIL_TOPS.md`。规则先提交（`b2771a9`），再运行。研究用途，不构成投资建议。

## 思路

Marshall Wace 的 TOPS 收集券商分析师的交易想法，按每个人过去的表现打分，再按分数分配仓位。这里把"分析师"换成 7 种公开的交易员方法，每种方法每天在同一个股票池里独立给出交易想法（买点、止损、卖出规则）。股票池按当时的数据筛选：实际股价不低于 $12，日均成交额不低于 $2000 万，包括后来退市的股票。

| 贡献者 | 交易员 | 规则要点 |
|---|---|---|
| Minervini VCP | Mark Minervini（1997、2021 年美国投资锦标赛冠军） | 之前验证过的 7 项形态打分前四分之一，收盘确认突破买入 |
| J Law 回踩 | J Law（2024、2025 年冠军） | 同样的形态，回踩后确认转强再买 |
| Qullamaggie 突破 | Kristjan Kullamägi | 前 3 个月涨 30% 以上，15 天窄幅整理，放量突破；止损在当天最低价 |
| Qullamaggie 跳空催化 | Kristjan Kullamägi | 放 3 倍量跳空高开 10% 以上，并守住开盘价 |
| Kell 均线回踩 | Oliver Kell（2020 年冠军） | 上升趋势里回踩 21 日均线后收盘创新高 |
| Darvas 箱体 | Nicolas Darvas | 52 周高点附近，放量突破箱体顶部 |
| Weinstein 第二阶段 | Stan Weinstein | 周线放量站上 30 周均线，相对强度向上 |

**加权方式**，三种：
- A 等权
- B 按历史表现加权（主版本，相当于 TOPS 的核心）：每月按贡献者过去 24 个月的平均 R 加权，样本少的向 0 收缩，表现为负的暂停
- C 在 B 的基础上，两个以上贡献者 10 天内看好同一只股票时加大仓位

每笔交易最多亏净值的 0.35%，单只股票不超过 15%，不加杠杆。

## 结果一：各位交易员的方法，单独看

| 贡献者 | 2017–21 每年想法数 | 2017–21 胜率 / 每笔 | 2022–26 胜率 / 每笔 | 两段都赚？ |
|---|---:|---|---|---|
| Minervini VCP | 12 | 46% / +0.65R | 46% / +0.34R | 是 |
| J Law 回踩 | 15 | 34% / +0.44R | 41% / +0.55R | 是 |
| Weinstein 第二阶段 | 19 | 22% / +0.18R | 21% / +0.30R | 是，但都不显著 |
| Qullamaggie 跳空催化 | 67 | 27% / +0.08R | 25% / 0.00R | 基本是 0 |
| Darvas 箱体 | 578 | 37% / +0.03R | 35% / −0.04R | 基本是 0 |
| Kell 均线回踩 | 6,778 | 30% / +0.07R（t = 8.1） | 27% / −0.02R（t = −2.3） | 前正后负 |
| Qullamaggie 突破 | 233 | 14% / −0.22R | 15% / −0.09R | 两段都亏 |

"每笔"是平均每笔赚到的风险倍数（R）。Minervini 和 J Law 用的打分规则之前已经在这两段数据上看过，所以它们的结果不是干净的检验。

## 结果二：按历史表现加权反而更差

| 组合 | 2017–26 夏普 | 2017–21 | 2022–26 | 最大回撤 |
|---|---:|---:|---:|---:|
| A 等权 | 0.14 | 0.51 | −0.07 | −35% |
| **B 按表现加权（主版本）** | **−0.03** | 0.24 | −0.23 | −30% |
| C 按表现加权 + 共识加分 | 0.02 | 0.38 | −0.27 | −32% |
| SPY 买入持有 | 0.73 | 0.94 | 0.49 | −34% |

两段时间里，按表现加权都比等权差，共识加分也没有帮助。加进实盘核心组合后夏普不变（2019–26 年 1.019 → 1.008），滚动计算给它的权重只有 1.2%。**按事先约定，不采用。**

## 为什么 TOPS 的做法在这里不灵

1. **加权是在追涨杀跌。** 贡献者的表现会翻转，按过去 24 个月加权，往往在它们刚表现好、接下来要变差的时候给最大权重：
   - Kell 2020–21 年表现好，2021–22 年权重最高，随后变成负的。
   - Minervini 2021 年表现差，2022 年权重被压到 0.08，而它 2023–24 年又恢复了。

   这和之前在 ETF 组合上测的"策略动量"是同一个问题。
2. **这些方法是公开规则，不是私有信息。** TOPS 能用表现打分，是因为分析师之间的能力差异是持续的：有人确实掌握别人不知道的信息。公开规则的表现差异主要来自市场环境，不能持续。
3. **规则化以后，大部分方法失去了作者的判断。**
   - Kell 的规则每年给出 6,000 多个想法，他本人只在少数领涨股里交易。
   - Kullamägi 的突破胜率只有 14%，他本人每天从全市场挑最强的 1%–2% 股票，还在盘中按开盘区间高点买入，日线规则复现不了。
4. **问题不是资金被挤占。** 看到结果之后我做了一个诊断：让每个贡献者各管 1/7 的资金，等权是 0.06，按表现加权是 −0.22，结论一样。

## 结论

- 这些公开方法里，两段时间都有正优势的只有形态质量类的 Minervini 和 J Law，以及交易很少的 Weinstein。而 Minervini 和 J Law 用的规则我们之前已经看过数据。
- 用 TOPS 的方式按历史表现给它们加权，在两段时间里都让结果变差。
- 和之前的结论一致：按历史表现动态调整权重，样本外站不住；能提高夏普的仍然是独立、稳定的收益来源。
